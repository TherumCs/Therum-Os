## Flags (should fix)

### C12: Four circular dependencies
- **File**: `lib/cache.ts ↔ lib/db.ts` · `services/connection.service.ts ↔ services/oauth.service.ts` · `site/storefrontHtml.ts ↔ site/productGrid.ts` · `site/storefrontHtml.ts ↔ site/shopToolbar.ts`
- **What**: madge reports 4 cycles across 184 files.
- **Why**: Inappropriate Intimacy (Fowler). `cache↔db` is the one that matters — the Prisma extension invalidates cache and the cache reads db, so a load-order change can yield a half-initialised client.
- **Fix**: extract the shared contract (cache-key types) into a leaf module both import.
- **Disproof**: not a defect if every cycle is type-only — cycles of `import type` erase at compile time. **Unverified**; check before spending effort.
- **Tier 2 · confidence HIGH** (tool-confirmed, exact).

### C4/C9: Browser `esc()` is weaker than the server's
- **File**: `site/productGrid.ts:575`, `site/accountPage.ts:219`, `site/orderTracking.ts:101`, `site/wishlist.ts:82`, `site/headerCart.ts:234`
- **What**: the five browser copies escape `[&<>"]`. The server's (`lib/render.ts:11`, `site/storefrontHtml.ts:16`) escape `[&<>"']` — including the single quote.
- **Why**: divergent duplicates of a security primitive. The weaker copy is XSS-exploitable the moment any of it lands in a single-quoted attribute.
- **Fix**: one shared browser `esc`, matching the server's character class.
- **Disproof**: harmless if no browser-built markup uses single-quoted attributes. Server-side sinks were checked and ARE safe — `productGrid.ts:366` and `:496` build `data-variants='…'` / `data-stills='…'` but use the **imported** server `esc`, which escapes `'`. The browser-built DOM strings were **not** exhaustively traced.
- **Tier 2 · confidence MEDIUM** (single method, disproof unresolved).

### C8: Unknown how many other test fixtures are fake
- **File**: `test/counter.test.mjs` (fixed), scope elsewhere unknown
- **What**: `asAdmin` was the literal string `th_session=admin-session-for-tests`, and passed only because the code checked the cookie's *name*. Its comment stated the hole as intent.
- **Why**: a test whose credential is fake proves the code accepts fakes. It is the reason a Tier 3 auth bypass survived a green suite.
- **Fix**: done for this file. **A sweep of the other 36 test files has not been run.**
- **Tier 2 · confidence HIGH** (proven once, by the failure it caused).

### C2/C3: Three files over 1000 lines
- **File**: `api/routes/wooCompat.ts:1308`, `site/productGrid.ts:1258`, `api/routes/storefront.ts:1142`
- **Why**: God Module. `wooCompat` carries two unrelated jobs — the WooCommerce-compatible REST surface, and the partner auth handshake with its own HTML screen, CSS and CSP.
- **Fix**: lift the handshake into `api/routes/wooAuth.ts`. It has its own tests already.
- **Tier 2 · confidence HIGH**.

### C6: 32 `as unknown as` casts
- **What**: double-casting to bypass the type system, e.g. `site.ts:71` reaching `req.server.jwt`.
- **Why**: each one is a place the compiler stopped helping.
- **Fix**: type the Fastify instance decorations once (`declare module 'fastify'`), which removes a good share of them.
- **Tier 1 · confidence HIGH**.

## Good Practices Found

- **Comments are the best thing in this codebase.** They explain *why*, and they
  record what already went wrong — `catalogSync.ts` on Printful's colour-code
  ordering, `auth.service.ts:80` on why rate limiting precedes the password
  check. That is institutional memory in the source, and it is rare. Scored 0.95.
- **Deep, small modules**: `counter/availability.ts` and `counter/visibility.ts`
  each expose a few functions over one definition, exactly Ousterhout's shape.
  `availableOf()` as the single definition of availability removed three
  duplicate bugs at once.
- **Validation at the boundary**: 16 Zod schemas, 126 parse calls across 42
  route files. Money is integer minor units throughout — no float drift.
- **Error handling is honest**: 227 catch blocks and only 9 empty, every one of
  those in browser code where `localStorage` throws in private mode. No swallowed
  server-side errors. (`gotchas.md` prompted checking the context before flagging
  — the empty catches read as C5 violations until you see they are inside
  template-literal browser runtimes.)
- **Test volume is real**: 1,318 assertions over 437 tests, including negative
  paths and a real RSA keypair for signature tests.
