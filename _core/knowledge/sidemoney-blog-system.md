**Blog** runs on the generic `Content` model, `type='post'` (no dedicated Post model). Public routes `/blog` + `/blog/:slug` in `src/api/routes/site.ts`; index cards via `indexCards()` (now renders `coverImage` + `excerpt` in an editorial grid — `siteHtml.ts` `.card`/`.card__cover`); the post page is the **Base-Theme shell** and returns the row's rendered body RAW (chromed pages), so each post BAKES its own `<article class="tsc-blog-post">` header (cover + h1 + date) into `body`, styled by per-post `meta.css`. Body shape = canvas: `{id:'root',type:'text',props:{__name:'div',content:'<html>'}}`, `bodyFormat:'canvas'`. Featured product cards/sliders/buttons are hand-built HTML in the body (`.tsc-feat__grid` 4-up, `.tsc-feat__slider` scroll-snap, `.tsc-shopbtn`) + their CSS appended to `meta.css`. **Create/edit posts** with a `.mjs` script that does `import { db, disconnectDb } from '../dist/lib/db.js'` (place under `scripts/`, run `cd /home/therum/therum && node --env-file=.env scripts/x.mjs`). Use `db.content.create` directly to set a custom `publishedAt`/`status` (contentService.create forces publishedAt=now + runs hooks). Gotchas: **Prisma 7** — bare `new PrismaClient()` throws (needs constructor config), so always import the app's `db`; **`disconnectDb()` hangs** (~90s timeout, exit 124) but the writes already committed — verify by DB/live, don't re-run. Localize external POD images before baking them into a post (`mediaService.upload({filename,mimetype,buffer})` → `.url`).
